# Stock Management System

A monorepo for the Stock Management System containing a Node.js/Express (TypeScript + Prisma + PostgreSQL) backend and a React (Vite + Tailwind CSS) frontend.

## Structure
- [Backend (server/)](./server/README.md)
- [Frontend (client/)](./client/README.md)

## Docs
- Authoritative requirements: [SRS](./docs/SRS.docx) and [Workflow](./docs/Stock_Management_Workflow.pdf)
- Conventions for contributors: [AGENTS.md](./AGENTS.md) and [CONTRIBUTING.md](./CONTRIBUTING.md)

## Getting Started

1. **Backend**:
   ```bash
   cd server
   npm install
   npm run dev
   ```

2. **Frontend**:
   ```bash
   cd client
   npm install
   npm run dev
   ```
